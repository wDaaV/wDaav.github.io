*Movie Matcher* is a Single Page Application, usable on both desktop and mobile devices, built with React for the Frontend, Node.js and Express (REST APIs) for the Backend and MongoDB used for complete data management. The main goal of the project is to give users the ability to organize themselves to choose and watch a movie together. Users can collect movies in their personal lists and join real-time multiplayer rooms (implemented with Socket.io), where participants challenge each other by selecting movies from their lists and competing over which movie gets watched through a *like and dislike* mechanism. Authentication is handled through Auth0, and movie information is provided by The Movie Database (TMDB). The application is deployed on Render.

The app is available [here](https://moviematcher.onrender.com/) (it is recommended to open it on a mobile device).
